# Notebooks

`original_2023/` holds the notebooks from the 2023 project, kept for reference. Only their hard-coded
Windows / Google Drive paths were replaced with relative paths; the code is otherwise unchanged and still
contains the bugs described in the main README ("What changed in 2026"). Their saved outputs are from 2023.

The reproducible 2026 pipeline lives in `src/` (see the main README, "How to run").
